# Found You

Веб-приложение для тех, кто собирается поделиться фотографией: оно показывает, что снимок выдаёт о месте, времени, устройстве и людях в кадре, и делает очищенную копию, никуда не загружая файл.

**Сайт:** https://foundyou.morgunov.tech · **Лицензия:** [MIT](LICENSE) · **English version:** [README.md](README.md)

## Что умеет

- **Открывает распространённые форматы фото:** JPEG, PNG, WebP, AVIF, GIF, BMP и HEIC/HEIF. HEIC декодируется локально: сначала `createImageBitmap`, затем `<img>`, затем встроенный в бандл `libheif-js`.
- **Читает метаданные:** EXIF, XMP, IPTC и ICC через `exifr`; для PNG ещё IHDR и чанки `tEXt`/`zTXt`/`iTXt` (например, prompt Stable Diffusion). Из HEIC блок EXIF извлекается из контейнера вручную.
- **Находит лица, людей и объекты** с помощью MediaPipe Tasks Vision: лица ищут два прохода BlazeFace (short-range и full-range, на кадре как есть и повёрнутом на 90° в обе стороны), людей и объекты — EfficientDet-Lite2 (метки COCO). Результат рисуется поверх фото вместе с описанием сцены простыми словами.
- **Распознаёт текст** через Tesseract.js (русский и английский) и ищет в нём номера машин, номера карт (проверка по алгоритму Луна), IBAN (mod 97), машиночитаемую зону паспорта, телефоны, адреса e-mail, имена аккаунтов и слова-маркеры документов. Текст на вывесках сверяется с улицей, номером дома и объектами рядом из уже полученных ответов; ничего дополнительно не отправляется.
- **Декодирует QR-коды** на устройстве (`BarcodeDetector` или встроенный `jsqr`) и объясняет, что в них: Wi-Fi с паролем, контакт, посадочный талон, платёжный код, ссылка-приглашение. Содержимое показывается под маской. Если QR-кода не нашлось, подгружается `zxing-wasm`, чтобы прочитать другие штрихкоды (PDF417, Aztec, Data Matrix, Code 128).
- **Перечисляет факты, а не выносит вердикты.** Секция «Что фото рассказывает о вас» охватывает, где сделан снимок (карта, объекты рядом), как (схема съёмки), когда, текст и коды, а также на что он сделан: устройство и система, даты создания и редактирования со следами правок, подлинность. У каждого факта — только данные, выводов о привычках нет. Кнопка «Показать сырые данные» раскрывает таблицу со всеми полями.
- **Проверяет подлинность:** следы AI-генераторов вплоть до модели и промпта, вероятность скриншота с причинами, таблицы квантования JPEG против камеры, указанной в EXIF, экспозиция против положения солнца, согласованность временных меток, Live/Motion Photo как признак нетронутого оригинала, серийные номера и Content Credentials (C2PA: самохостящийся тулкит `c2pa` загружается, только если в файле есть подписанный манифест, и проверяет его). Карточка «Проверка кадра» по запросу прогоняет три проверки пикселей (карта ошибок сжатия для вклеенных или перерисованных участков, сколько раз файл сохраняли как JPEG, карта шума для участков с чужим зерном) и для каждой объясняет, что сделано, что искали, что вышло и чего это не доказывает.
- **Определяет, откуда файл:** один судья (`src/utils/originJudge.ts`) сводит блок камеры в EXIF, имя файла, размер на пределе мессенджера, таблицы квантования, метки Live/Motion Photo, даты, размер против записанного камерой и миниатюру в одну строку с уровнем уверенности и основаниями.
- **Оценивает утечку:** индекс от 0 до 100 с карточками и весами, из которых он сложился; помечен как оценка, а не факт. Тот же расчёт предсказывает индекс очищенной копии при выбранных настройках (например, «73 → 20»).
- **Добавляет контекст места**, если в EXIF есть координаты: адрес, историческая погода на час съёмки, праздники, объекты рядом (заведения в 250 м, достопримечательности в 1 км, парки в 500 м, природные объекты и населённые пункты в 1,5 км), камеры наблюдения, отмеченные в OpenStreetMap, в радиусе 300 м и карта (MapLibre GL, растровые тайлы OSM). Схема съёмки строится по GPS и тегам камеры: направление и угол обзора, вертикальный или горизонтальный кадр, фронтальная или основная камера, скорость, положение солнца (алгоритм NOAA), часы камеры против часового пояса места, высота GPS против рельефа. Подсказка объясняет, как выключить геометки, для производителя и модели устройства из EXIF.
- **Делает безопасную копию:** перекодирует через `<canvas>`, вычищает сегменты, которые браузер добавляет сам (ICC-профиль, COM и т. п.), затем заново разбирает результат через `exifr` и показывает «было N полей метаданных, осталось 0». Пресет «Только метаданные» сохраняет пиксели JPEG/PNG байт в байт и удаляет только сегменты метаданных и всё, что идёт после конца изображения (трейлер Samsung, Motion Photo); остальные исходники перекодируются один раз с наивысшим качеством.
- **Настройки очистки:** размытие лиц, OCR-текста, номеров машин, QR-кодов, документов и контактов или участков, закрашенных кистью; ослабление отпечатка сенсора камеры (PRNU, включено по умолчанию); защита от поиска по картинке трёх уровней, сила которой подбирается по перцептуальному хешу до расстояния 10, 14 или 18 бит из 64; зеркалирование; уменьшение; водяной знак; формат (исходный, JPEG, PNG, WebP) и качество; нейтральное имя файла `photo-xxxxxx.ext` (включено по умолчанию). Там, где доступен Web Share API (iOS, Android, macOS Safari), кнопка «Очистить и отправить» передаёт файл прямо в меню «Поделиться», минуя галерею.
- **Три языка, четыре темы:** русский, английский и узбекский по адресам `/`, `/en/` и `/uz/`, у каждого свои заголовок, описание, `hreflang`, JSON-LD и статическая копия текста страницы для роботов, которые не выполняют JavaScript. Темы: светлая, тёмная, авто, высококонтрастная.

## Приватность

**Фото не покидает браузер.** Файл и его пиксели остаются на устройстве. Разбор метаданных, детекция, OCR, эвристики профиля, очистка, экспорт и проверка результата выполняются там же и не делают сетевых запросов.

**Что получают Functions.** Только если в EXIF есть координаты, страница сама запрашивает контекст места у собственных Cloudflare Pages Functions сайта и прямо под результатом пишет, что было отправлено:

- широта и долгота, округлённые до 4 знаков (~11 м) ещё на клиенте (`src/hooks/useGeoContext.ts`) и повторно на сервере;
- дата и время съёмки (`timestamp` в ISO и `local` — настенные часы камеры), только для запроса погоды;
- код страны из ответа геокодера и дата, только для запроса праздников (по коду страны также выбираются языковые разделы Википедии для достопримечательностей).

Изображение, имя файла и остальные метаданные не отправляются.

| Эндпоинт | Получает | Апстрим |
|---|---|---|
| `/api/reverse-geocode` | `lat`, `lon` | Nominatim |
| `/api/historical-weather` | `lat`, `lon`, `timestamp`, `local` | Open-Meteo Archive |
| `/api/elevation` | `lat`, `lon` | Open-Meteo Elevation (Copernicus GLO-90) |
| `/api/nearby-poi` | `lat`, `lon` | Overpass (OSM) |
| `/api/surveillance-candidates` | `lat`, `lon` | Overpass (OSM) |
| `/api/place-context` | `lat`, `lon` | Overpass (OSM) |
| `/api/landmarks` | `lat`, `lon`, `country` (необязательно) | геопоиск Википедии |
| `/api/holidays` | `country`, `date` | Nager.Date; для стран, которых там нет, — встроенная таблица (сейчас только UZ) |
| `/api/tiles/{z}/{x}/{y}.png` | координаты тайла | tile.openstreetmap.org |

**Functions — прокси только для этого сайта.** Каждый обработчик принимает только GET/HEAD, проверяет `Sec-Fetch-Site` (с откатом на `Origin`/`Referer`) и всем остальным отвечает 403, валидирует параметры, обращается к апстриму с общим User-Agent и таймаутом 8 с, не раскрывает текст ошибок апстрима, кэширует успешные ответы на edge по округлённым координатам и отдаёт `X-Robots-Tag: noindex`. IP пользователя апстримы не видят. Браузеру ответы приходят с `Cache-Control: no-store`, чтобы адрес, найденный по координатам, не оседал в дисковом кэше браузера.

**Карта грузится только по запросу.** Тайлы запрашиваются лишь после нажатия «Показать карту» и идут через `/api/tiles`, поэтому OpenStreetMap видит адрес Cloudflare и наш User-Agent, а не читателя. На edge тайлы кэшируются на неделю, а браузеру отдаются с `no-store` (кэш тайлов на устройстве — это история мест).

**Модели и рантаймы самохостятся.** Tesseract (worker, ядро, языковые данные), WASM-рантайм MediaPipe и модели детекции, тулкит Content Credentials и декодер штрихкодов `zxing-wasm` раздаются с домена приложения; во время работы ничего не грузится с CDN. Единственное обращение к третьей стороне при сборке — `prepare:assets` скачивает модели `.tflite` с `storage.googleapis.com` (закреплённая версия, проверка размера и MD5).

**Сетевой страж блокирует телеметрию.** MediaPipe Tasks Vision отправляет статистику использования на `odml.pa.googleapis.com`, и выключить это нельзя. Её останавливают два слоя: `src/utils/networkGuard.ts` оборачивает `fetch`, `XMLHttpRequest` и `sendBeacon` и отбрасывает любой запрос со страницы к чужому хосту (в том числе на dev-сервере и в `vite preview`), а в продакшене то же запрещает CSP. Как проверить это самому, объясняет сама страница: ссылка «Как проверить, что фото никуда не уходит» под кнопкой загрузки.

**Без аналитики и cookies.** В `localStorage` хранятся только `theme-preference` и `meta-data-lang`. Tesseract.js держит языковые данные (`rus`, `eng`, около 10 МБ) в IndexedDB, чтобы не скачивать их при каждом визите; ничего о пользователе или фото там не хранится.

**Заголовки безопасности** (`public/_headers`): CSP без единого стороннего хоста (`default-src 'self'`, `connect-src 'self'`, `frame-ancestors 'none'`), HSTS, `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: strict-origin-when-cross-origin`, Permissions-Policy, которая запрещает камеру, микрофон, геолокацию и другое, и COOP `same-origin`. Для `/api/*` заголовки ставятся в `functions/api/_geo.ts`, потому что `_headers` на Functions не действует.

## Ограничения

- **Размер файла:** до 50 МБ и 120 мегапикселей (60 на iPhone и iPad). Экспорт ограничен 40 Мп (16 Мп на iOS/iPadOS), предпросмотр — 2400 px по длинной стороне.
- **OCR читает только русский и английский.** Отдельной модели для номеров машин нет: кандидаты выбираются из распознанного текста (токены, похожие на номер, и короткие буквенно-цифровые токены в нижней части найденного транспорта).
- **Размытие лиц закрывает только найденные лица.** Людей, чьё лицо не распознано (спиной, в маске), нужно закрыть кистью.
- **Детекция может быть недоступна.** Если рантайм MediaPipe или модель не загрузились, страница сообщает об этом и отключает опцию размытия лиц.
- **Проверки подлинности — сигналы, а не доказательства.** Без манифеста C2PA проверка на AI-генерацию опирается только на метаданные, и страница так и пишет. Каждая проверка кадра говорит, чего она не доказывает; индекс утечки помечен как оценка.
- **Контекст места зависит от публичных сервисов** (Nominatim, Open-Meteo, Overpass, Nager.Date, Википедия). Ответ 429 не повторяется автоматически, только кнопкой «Повторить», потому что публичные серверы за это банят. Погода доступна только для дат с 1940-01-01 по завтрашний день.
- **Различия браузеров:** без поддержки фильтров на canvas (Safari до 18) размытие заменяется пикселизацией; формат, который браузер не умеет кодировать, экспортируется как JPEG с уведомлением; «Очистить и отправить» появляется только там, где Web Share API умеет передавать файлы.

## Технологии

- **Приложение:** React, TypeScript, Vite; одностраничное приложение без бэкенда и базы данных.
- **В браузере:** `exifr` (метаданные), `libheif-js` (HEIC), `@mediapipe/tasks-vision` (лица и объекты), `tesseract.js` (OCR), `c2pa` (Content Credentials), `jsqr` и `zxing-wasm` (коды), `maplibre-gl` (карта), `@photostructure/tz-lookup` (часовой пояс места).
- **Серверная часть:** Cloudflare Pages Functions на TypeScript (`functions/api/`) с общими помощниками в `functions/api/_geo.ts` и одним запросом Overpass в `functions/api/_overpass.ts`. На Functions направляется только `/api/*` (`public/_routes.json`).
- **Качество:** Vitest, ESLint, Prettier, браузерный smoke-тест на `playwright-core`. GitHub Actions запускает линтер, проверку типов, тесты, сборку и smoke-тест на каждый пул-реквест и пуш в `main`.
- **Дизайн:** дизайн-система morgunov.tech v1, скопированная в `public/ds/v1/`. Шрифты — IBM Plex Sans и Mono (© IBM Corp.) под SIL Open Font License 1.1 (`public/fonts/OFL.txt`); лицензия MIT на них не распространяется.

```
src/            приложение: App.tsx, components/, hooks/, utils/ (анализ и очистка), i18n/,
                site/ (статический текст страницы, head, JSON-LD, sitemap.xml, llms-full.txt)
functions/api/  Pages Functions, по файлу на эндпоинт; общие помощники в _geo.ts и _overpass.ts
public/         _headers, _routes.json, дизайн-система и шрифты;
                ocr/, mediapipe/, c2pa/, zxing/ генерирует prepare:assets
scripts/        prepare-assets.mjs, smoke.mjs и вспомогательные скрипты
docs/           аудит, ADR и заметки по ревью
```

Раньше проект назывался Meta Data Insight; npm-пакет по-прежнему называется `meta-data`.

## Локальный запуск

Нужен Node 22 (`.nvmrc`; точный диапазон — в поле `engines` в `package.json`).

```bash
npm ci
npm run prepare:assets   # один раз после установки и после обновления tesseract.js или @mediapipe/tasks-vision
npm run dev              # http://localhost:5173
```

`prepare:assets` (`scripts/prepare-assets.mjs`) копирует рантаймы Tesseract, MediaPipe, `c2pa` и `zxing-wasm` из `node_modules` в `public/` и скачивает три модели `.tflite`; результат в git не попадает. В dev-режиме `/api/*` работает на том же коде Functions, что и в продакшене, через плагин Vite (`functionsDevProxy` в `vite.config.ts`), только без edge-кэша. `VITE_FUNCTIONS_BASE` направляет `/api/*` на другой хост.

## Тесты

```bash
npm run lint           # ESLint
npm run typecheck      # tsc --noEmit
npm test               # юнит-тесты Vitest, включая Pages Functions
npm run format:check   # Prettier
npm run build          # prepare:assets + typecheck + vite build
npm run smoke          # браузерный smoke-тест против запущенного dev-сервера (нужен Chrome)
```

Тесты Functions вызывают `onRequest` напрямую с подменёнными `fetch` и `caches.default` (`src/__tests__/functions/_harness.ts`), поэтому проверяют настоящие коды ответа, заголовки и кэширование без Cloudflare.

## Деплой

Cloudflare Pages собирает и выкладывает `main` через интеграцию с Git; Functions подхватываются из `functions/` автоматически.

- **Build command:** `npm run build`
- **Build output directory:** `dist`
- **Node:** версия из `.nvmrc`; при необходимости задайте `NODE_VERSION`.

Сборке нужен доступ в интернет: `prepare:assets` скачивает модели MediaPipe, которых нет в репозитории. `public/_headers` и `public/_routes.json` копируются в `dist/` как есть. В футере есть ссылка на выложенный коммит (`CF_PAGES_COMMIT_SHA`).
