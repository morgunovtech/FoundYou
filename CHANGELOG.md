## Не выпущено — 2026-09-26, видимость для роботов

По сигналу TofsDevOps (две «помехи в поиске» у foundyou.morgunov.tech), проверено теми же запросами, что делает бот.

- **Текст без JavaScript.** Страница отдавала роботам 86 символов видимого текста — только `<title>`; ИИ-ассистенты и текстовые краулеры JavaScript не запускают и видели пустой `<div>`. Теперь в `#root` лежит статическая копия героя (заголовок, лид, четыре пункта, строка о приватности) на трёх языках; критический CSS показывает блок того языка, который `theme-init.js` ставит на `<html lang>` до первой отрисовки, а React при монтировании заменяет его живым героем. Тест `staticHero.test.ts` сверяет копию со словарём по слову.
- **Ответ 404.** Cloudflare Pages без `404.html` отдаёт `index.html` со статусом 200 на любой адрес (SPA-фолбэк), и робот видит сайт, где существует любой адрес. `404.html` — второй вход Vite, с тем же DS и штампами версий; у приложения нет клиентских маршрутов, только якоря `#sec-*`, так что фолбэк ничему не нужен.

По аудиту `docs/seo-geo-audit-2026-09-26.md` (66/100; главное — сайт не проиндексирован ни в Google, ни в Bing, и это чинится не кодом, а подачей в Search Console и Вебмастер):

- **Три языка — три адреса.** `/` (русский, он же `x-default`), `/en/` и `/uz/` — статические входы Vite, отрендеренные из одного `index.html` и словаря (`localePages()` в `vite.config.ts`, `src/site/renderStatic.ts`): у каждой страницы свой `<title>` (≤ 75 символов вместо двуязычных 86), описание (≤ 160 вместо 278), canonical, набор `hreflang`, Open Graph с `og:locale:alternate uz_UZ`. Раньше язык выбирал `navigator.languages` на одном адресе: Google индексировал английскую версию под русским заголовком, Яндекс — русскую, узбекскую не видел никто. Адрес теперь задаёт язык (`src/i18n/locale.ts`, `initialLanguage(pathLang, …)`); сохранённый выбор другого языка с `/` уводит на свою страницу до первой отрисовки (`theme-init.js`), переключатель меняет язык на месте и переписывает адрес через `replaceState`, чтобы загруженное фото не пропадало.
- **Текст страницы виден без JavaScript.** Под зоной загрузки — «Что фотография рассказывает о вас» (семь определений), «Как это работает», «Что удаляется, а что остаётся» (таблица двух пресетов), «Как выключить геометки» (восемь рецептов из словаря), «Вопросы» (шесть) и «Кто это сделал»; на всех трёх языках, из одной модели (`src/site/siteContent.ts`) для статической копии и для React (`components/SiteContent.tsx`). Роботу достаётся ~7 700 символов вместо 350 слов героя.
- **JSON-LD говорит правду.** Один `@graph`: Organization, WebSite, WebApplication с `datePublished` 2026-09-15 (стояло 2024-06-01 — дата, в которую ничего не публиковалось), `dateModified` и `softwareVersion` из сборки, `isAccessibleForFree`, и FAQPage из тех же шести вопросов, что видны на странице — прежняя разметка описывала три вопроса, которых на странице не было, на двух языках сразу.
- **`sitemap.xml` и `llms-full.txt` собираются на сборке**: три адреса с `lastmod` из даты коммита и `xhtml:link`-альтернативами; полный справочник для ИИ-ассистентов — весь текст страницы по-английски. `llms.txt` перечисляет три страницы и ссылается на полный.
- **Футер называет версию и дату** («версия 1.4.0 от 2026-09-26») рядом с хешем сборки; `meta keywords` убран.
- **Кнопка «Выбрать фото» — настоящая `<button>`** внутри обычного `<label>`: `label` с `role="button"` не проходил ни один аудит доступности (роль там не разрешена, имя не совпадало с текстом), теперь имя — текст кнопки, клавиатура — родная.
- **Словари вынесены в `src/i18n/messages.ts`** без React, чтобы конфиг Vite мог рендерить страницы из них; `src/i18n/index.tsx` реэкспортирует всё, импорты в коде не меняются.
- **Не сделано кодом, потому что это не код:** подача в Search Console, Яндекс Вебмастер и Bing; выключение Cloudflare Web Analytics в проекте Pages (маячок вставляется в HTML и блокируется CSP — три ошибки в консоли у каждого посетителя); публикация репозитория, на который ведут ссылки «репозиторий на GitHub» и хеш сборки (он приватный, ссылки отдают 404).

## Не выпущено — 2026-09-24, продуктовое ревью

Правки по `docs/product-review-2026-09-24.md` (свежий взгляд на живую страницу: образец, скриншот без метаданных, фото из Telegram, HEIC, три языка, две темы, 800 и 375 px).

### Сервис перестал спорить сам с собой

- **Один судья происхождения** (`src/utils/originJudge.ts`): блок камеры в EXIF, имя файла, размер на пределе мессенджера, таблицы квантования против производителя, метки Live / Motion Photo, дата изменения, программа-редактор, размер против записанного камерой, миниатюра, метка генеративной правки и скриншот-скор сводятся в одну строку «Уверенно / Скорее всего / Предположительно: …» с перечнем оснований. Строка стоит первой в «Истории файла», в профиле и в сырых данных; «Дата редактирования» больше не пишет «не редактировался» под вердиктом «перезаписан», а строка Live Photo под таким вердиктом говорит, что метка скопирована при сохранении. Раньше на образце четыре строки одной карточки давали два разных ответа, а фото из Telegram называлось «Оригинальный файл (не из мессенджера)».
- **Остаток EXIF — не «метаданные сохранены».** Шесть полей (`XResolution`, `ExifImageWidth`…) пишет любой перекодировщик, и «больше двух ключей EXIF» считало их блоком камеры; теперь блок камеры — это `Make` / `Model` / `DateTimeOriginal` / объектив / экспозиция (`hasCameraExif`).
- **Имена Telegram с macOS и iOS** (`photo_2022-03-08 13.33.59.jpeg`, с пробелом и точками, и `photo_12@08-03-2022_13-33-59.jpg` из Telegram Desktop) теперь распознаются; все 43 файла бенча носили первое имя, и ни один не был узнан.
- **Образец перегенерирован** через ImageIO (собственные таблицы, как у камеры Apple) с тем же блоком EXIF, так что первый экран сервиса больше не показывает противоречие; 465 КБ вместо 419.
- **Лицо внутри бокса животного и вне бокса человека отбрасывается** до всех остальных проверок: на образце морда собаки шла как «ЛИЦО» с 0,63, «Лица (2)», «2 чел.» и +20 к индексу.
- **Индекс утечки называет карточки, которые есть на странице:** шесть секций профиля внутри «На что сделан снимок» суммируются в одну строку, люди — «Люди и лица (раздел 01)», а цифровой отпечаток, который есть у любого файла, больше не даёт +5. Под индексом — «В файле нет: даты съёмки, координат, устройства» вместо пустых карточек «дата не найдена».
- **Полоски риска у карточек убраны**: цвет без легенды был вердиктом, а правило с 16.09 — факты без вердиктов. Заголовок карточки устройства без EXIF — «Устройство неизвестно: метаданных камеры в файле нет», а не «Оригинальный файл».
- **Индекс после очистки**: в сводке «Что изменится» и после экспорта — «Индекс утечки: 73 → 20» по тем же весам (`predictLeakAfter`): метаданные уходят с контейнером, лица, текст, номера, коды и документы — с размытием, которое их закрывает.

### Очистка смотрит на файл

- **Качество по умолчанию — как в оригинале**, когда таблицы говорят, что оно ниже 90 (режим «Как в оригинале (~80 %)»): копия с 90 % от 80 % оригинала выходила больше оригинала.
- **Скриншот и PNG** по умолчанию идут путём «Только метаданные»: PRNU выключен (следа сенсора нет), качество не показывается («Без потерь · копия ≈ …»), в сводке — «формат без потерь» вместо «Качество: Среднее (90%)».
- **Строка отпечатка после экспорта** — нейтральный факт, пока защита от поиска выключена; предупреждение только когда она была включена и не достигла цели.
- **Водяной знак** переехал из блока «Метаданные» в свой блок «Подпись сервиса»: это не метаданные и не защита.

## Не выпущено — 2026-09-23

Исправления по итогам полного код-ревью 23.09 (восемь зон кода, каждая находка подтверждена по коду, часть — измерением в Chromium).

### Очистка фото: то, что показано, и то, что скрыто, — одно и то же

- **Кисть закрывает в экспорте то же, что рисует на предпросмотре.** `blurManualMasks` обрезал размытие по *заливке многоугольника* из точек мазка: почти прямой мазок по бейджу замыкался в тонкий клин, и, измерено, экспорт менял около десятой доли пикселей, которые закрывал оверлей. Теперь маска растеризуется той же фигурой, что и оверлей, — полоса шириной 2·радиус с круглыми концами плюс внутренность замкнутой петли — и накладывается через `destination-in`; ширина линии на оверлее — те же 2·радиус. Тап по-прежнему диск радиуса кисти.
- **Прямоугольное размытие больше не просвечивает по краям.** Слой под `filter: blur()` прозрачен снаружи нарисованного, и слой ровно в размер бокса гас до α ≈ 0,5 на границе — при 28 px буквы 40 px оставались тёмными призраками. Слой теперь шире бокса на 3σ, а у края кадра картинка зеркалится в запас. Измерено на том же тексте: самый тёмный пиксель внутри бокса 65 → 212, у бокса на краю кадра — то же.
- **«Только метаданные» для PNG — по списку на сохранение.** Список на удаление знал `tEXt`, `iCCP`, `eXIf`, но не `caBX`: манифест Content Credentials переживал экспорт, а проверка честно отвечала «0 полей», потому что exifr `caBX` не читает. Теперь остаются только чанки, нужные декодеру (критические четыре, цвет / прозрачность / размер, тройка анимации). В JPEG `APP0` сохраняется только как `JFIF` (миниатюра `JFXX` — та же картинка, только маленькая), `APP14` — только как `Adobe`. Формат определяется по байтам, не по расширению: JPEG с именем `.png` раньше уходил нетронутым.
- **«Было N полей» на PNG больше не считает заголовок IHDR** (семь структурных полей, которые не удаляет ни один экспорт): пустой PNG показывал «было 7 полей, осталось 0».
- **Экспорт, начатый на одном фото, не дописывает результат на другое.** `exportCleanFile` не меняет состояние сам; вызывающий сверяет фото с текущим и только тогда показывает проверку и флаг ограничения.
- **Сводка пресета «Только метаданные» не обещает уменьшение.** Для файла выше платформенного лимита она показывала «8064×6048 → 4618×3464» и размер перекодированного JPEG, а отдавала оригинал байт-в-байт. Теперь — размер исходника и байты после зачистки контейнера.

### Приватность

- **Страж сети.** `@mediapipe/tasks-vision` заводит на каждый детектор логгер, который раз в 60 секунд отправляет protobuf на `odml.pa.googleapis.com` с ключом, вшитым в WASM, и выключателя у него нет. Измерено: три запроса через минуту после разбора примера. В продакшене их держал только CSP; на dev-сервере, в `vite preview` и в smoke они уходили. `src/utils/networkGuard.ts` ставится первым в `main.tsx` и отбрасывает любой `fetch`, `XMLHttpRequest` и `sendBeacon` к хосту, кроме собственного и `tile.openstreetmap.org`, — тем же списком, что `connect-src`. Измерено после: три попытки видны как `network-guard` в консоли, наружу не уходит ничего. Тулкит c2pa создаётся с `fetchRemoteManifests: false`.
- **Ответы `/api/*` отдаются браузеру с `no-store`.** Раньше — с `public, max-age` на сутки, неделю, месяц, и адрес по координатам оседал в дисковом кэше браузера; публичный `max-age` остался только у копии в edge-кэше.
- **Тайлы карты не кэшируются браузером** (`transformRequest` с `cache: 'no-store'`): кэш тайлов — это история мест.
- **Публичные тексты больше не обещают выключатель контекста места и не те лимиты.** JSON-LD, FAQ, Open Graph, `llms.txt`, `README.md`, `manifest.json` и описания в `App.tsx` говорили «can be switched off» и «20 MB / 40 megapixels» (в коде 50 МБ и 60/120 Мп). Убраны меты `apple-mobile-web-app-capable`, которые спорили с `display: browser`.

### Факты

- **IPTC `Credit` не показывается как автор.** Файл после iOS Clean Up / Magic Editor / Galaxy AI получал карточку «Автор: Apple Photos Clean Up». `Credit` и `Source` — строки авторства рядом с правами.
- **`/api/landmarks` при отказе всех разделов Википедии отвечает 502**, а не кэширует пустой список на неделю как факт (он давал −3 в «это место, где вы живёте»). У разделов общий дедлайн; неполный пустой ответ хранится час. Клиент спрашивает один раз, дождавшись страны из геокодера, — раньше запросов было два.
- **Часовой пояс камеры по GPS.** Разница «часы камеры минус время GPS» округлялась к четверти часа всегда: часы, ушедшие на 8 минут вперёд в UTC+5, давали «UTC+05:15, на 15 минут впереди места» и «отстают на 7 минут». Теперь округление принимается только в пределах двух минут от четверти часа; дальше пояс берётся у места (карточка так и говорит), а весь остаток — дрейф.
- **Сумма с пробелами — не телефон.** «Итого: 1 000 000 000 сум» становилось находкой «телефон» и боксом размытия на чеке; `00` теперь только перед кодом страны, а три нуля подряд — число. Зато «8 (495) 123-45-67» с пробелом и скобкой читается. `STIR` — только с номером после него, а не в «stir fry».
- **`building=yes` — не «жилой дом»** в подсчёте «это место, где вы живёте».
- **Узбекская таблица меток COCO — все 80 классов** (было 30, остальные подставлялись по-английски посреди узбекской фразы); русские формы множественного числа — все 80 (было 13: «3 ноутбук»); английское множественное знает bus → buses, knife → knives, sheep, mouse → mice. Тест закрепляет полноту таблиц.
- **Nominatim «Unable to geocode»** больше не превращается в английское «Unknown address» посреди русской карточки: поля просто отсутствуют, карточка берёт свой ключ словаря.
- **Wi-Fi-код с SSID первым полем** (`WIFI:S:…;T:…`, как пишет Android) читается.

### Устойчивость к кривым файлам

- Bplist-ридер Apple MakerNote получил бюджет чтений: общие ссылки в bplist законны, и защита от циклов «только по пути» была экспоненциальной — 22 уровня занимали 742 мс, 40 умещались в 250 байт.
- `iloc` в HEIC ограничен по числу extents и items, и курсор проверяется внутри цикла: 40 записей в 319 байтах занимали 154 МБ.
- Распаковка `zTXt`/`iTXt` ограничена 8 МБ на выходе: лимит был на сжатый размер, а deflate из нулей раздувается в тысячу раз.
- `parseCoord` в Functions: длина до 32 символов и регэксп без наложения — на 16 000 цифр он откатывался 137 мс.
- `fetchUpstream` читает тело под тем же таймером, что и заголовки; раньше таймер снимался после заголовков.
- `Sec-Fetch-Site: same-site` больше не принимается, только `same-origin`.
- `useAPIFetch` не повторяет 429 автоматически — публичные серверы банят за это; кнопка «Повторить» осталась.

### Хуки и интерфейс

- `useImageFile` и `useExifMetadata` возвращают коды, а не переведённые строки: `t` в зависимостях второго заново разбирал файл при смене языка и повторял все запросы контекста места; ошибка, показанная до переключения, оставалась на старом языке.
- Хэши файла считаются один раз на файл, а не при каждом приходе OCR/QR/детекций; отказ `crypto.subtle` или `arrayBuffer()` даёт `hash: null`, а не вечное «ждём факты».
- Предпросмотр пересчитывается только от входов включённых опций, а не при каждом приходе OCR и QR.
- Картинка не декодируется дважды на файл (`sourceImageRef` очищается только когда держит другой файл); `useFrameStats` декодирует сразу в рабочий размер; индикатор OCR не показывает прогресс предыдущего файла.
- `I18nProvider` читает и пишет хранилище под try/catch — WebKit с заблокированным хранилищем бросает исключение на самом `localStorage`, а это корневой провайдер; `formatMessage` подставляет через split/join (`$&` в имени файла безопасен, повторный плейсхолдер заполняется).
- Меню языка и темы не сбрасывают фокус на отмеченный пункт при каждом перерисовывании шапки.
- Поверхность кисти — `role="application"` с честной подсказкой «мышью или пальцем; с клавиатуры маску нарисовать нельзя»; имя кнопки загрузки — только её текст; inline-`ErrorBoundary` берёт подписи из словаря.
- Дизайн-система: шеврон селекта — рамка, а не два градиента; фон лайтбокса — из токена; мёртвые классы `v4-lang-btn`, `v4-theme`, `v4-theme-menu` и правило `.v4-lang` под DS-префиксом убраны (`.fy-lang`); `@types/geojson` добавлен в devDependencies.

### Новые факты из открытых данных (#62)

- **Автор и контакты в метаданных**: IFD0 `Artist`, `CameraOwnerName`, `XPAuthor`, контактный блок и байлайн IPTC, строки прав. - **Место, записанное словами**: город, район, страна из IPTC/XMP, когда координат нет. Текст принципиально не геокодируется.
- **Тип помещения по объектам COCO**: кровать и телевизор — жильё, ноутбук с клавиатурой и мышью — рабочее место, унитаз — ванная, светофор и машина — улица. У каждого предмета вес; вывод не делается, пока победитель не оторвётся от второго места. Отказ — обычный исход.

Без фокусного расстояния строка с дистанцией не показывается вовсе.

Лишнего запроса наверх не стоит: общий кэшированный ответ Overpass теперь режется на три набора.
- **Известные места рядом** (`/api/landmarks`): статьи Википедии о точке, в языковых разделах по стране. Пятый внешний апстрим — решение, а не настройка: наружу уходит то же самое, запрос делает Cloudflare, IP читателя до Википедии не доходит.

Посадочный талон — это PDF417, и сервис отвечал «ничего не найдено» на кадр, где в коде лежат фамилия пассажира, локатор брони и рейс. ### Секция очистки: лица, «не обнаружено», защита от поиска

- Блок «Скрыть»: строки называются одинаково («Лица (N)», «Текст (N)», «Номера машин (N)»); когда модель ничего не нашла, вместо неактивного тогла показывается строка «Лица: не обнаружено» (для текста во время распознавания — «распознаём…») и подсказка закрыть нужное кистью. - Блок «Защита от поиска»: тогл, уровень, «Отзеркалить», строка состояния и пояснение, что именно делает защита, теперь внутри блока; надпись под блоками убрана.
- Защита от поиска стала измеряемой (`applyAntiSearchMeasured`, `smoothField`): к обрезке, наклону, шуму и сдвигам цвета добавлено плавное поле освещённости (несколько широких светлых и тёмных пятен), которое и двигает низкочастотные биты перцептуального отпечатка; сила поля и обрезки растёт, пока расстояние до отпечатка оригинала не достигнет цели уровня: 10, 14 или 18 бит из 64. Сводка и строка состояния показывают цель и достигнутый по предпросмотру сдвиг.

- Наличие манифеста определяется разбором контейнера без библиотек (`detectC2paPresence` в `src/utils/contentCredentials.ts`): JPEG APP11 с JUMBF-боксом `c2pa`, PNG `caBX`, WebP `C2PA`, HEIC/AVIF `uuid` с UUID C2PA или `jumb`. Для файлов без манифеста тулкит не загружается вовсе.

Детали факта показывают таблицу подписи и результат проверки. В рассказе появились предложения про подпись.

## 1.0.0 — 2026-09-15

Первый версионированный релиз Found You (ранее Meta Data Insight). Итог аудита и спринта исправлений от 2026-09-15.

### Детекция

- Стек детекции заменён: TensorFlow.js + `@tensorflow-models/coco-ssd` (`lite_mobilenet_v2`; оба пакета не обновлялись с 2023–2024, 302 МБ в `node_modules`) → `@mediapipe/tasks-vision`. FaceDetector (BlazeFace short-range, 230 КБ) находит лица, ObjectDetector (EfficientDet-Lite0 float16, 7,2 МБ, метки COCO) — людей и объекты для описания сцены. Один WASM-рантайм (~11,7 МБ), делегат CPU по умолчанию (первый инференс ~100 мс против ~5 с компиляции шейдеров на GPU), GPU (WebGL2) как запасной; без WebGL детекция работает, фатально только отсутствие WebAssembly.

Выбор областей вынесен в чистую функцию `selectBlurTargets` (`src/utils/cleanup.ts`) с юнит-тестами; описание сцены игнорирует рамки лиц.

### Приватность и безопасность

- Контекст места (адрес, погода, праздники, объекты и камеры поблизости, карта) стал opt-in: до нажатия «Показать контекст места» ни один сетевой запрос не выполняется. Согласие действует на одну фотографию и переживает смену языка.
- На сервер уходят только координаты, округлённые до 4 знаков (~11 м) на клиенте и повторно на сервере, плюс дата и время съёмки; ответ геокодера описывает округлённую точку.
- Functions защищены общим `defineHandler`: только GET/HEAD (405), проверка `Sec-Fetch-Site` / `Origin` / `Referer` (403), строгий `parseCoord` с диапазонами (400), таймаут апстрима 8 с, единый User-Agent `FoundYou/1.0`, статусы 429 / 502 / 504 вместо `200 + ok:false`, текст ошибок апстрима не передаётся клиенту, `X-Robots-Tag: noindex` и `no-store` для ошибок.
- Добавлен `public/_headers`: CSP (`default-src 'self'`, `script-src 'self' 'wasm-unsafe-eval'`, единственный сторонний хост — `tile.openstreetmap.org`), HSTS, nosniff, `X-Frame-Options: DENY`, Referrer-Policy, Permissions-Policy, COOP; кэш-заголовки для статики. `public/_routes.json` ограничивает Functions маршрутом `/api/*`.
- Tesseract (worker, WASM-ядра, traineddata `rus`/`eng`) и MediaPipe (WASM-рантайм и модели) самохостятся из `public/ocr` и `public/mediapipe`; на этапе выполнения ничего не загружается с CDN. Генерацию делает `scripts/prepare-assets.mjs`, встроенный в `npm run build`.
- Экспорт проходит зачистку контейнерных метаданных (`src/utils/containerMetadata.ts`): из JPEG удаляются APP1–APP15 (кроме APP0/APP14) и COM, из PNG — `iCCP`, `tEXt`, `zTXt`, `iTXt`, `eXIf`, `tIME` и др. Это убирает ICC-профиль, который добавляет сам браузер.
- Проверка результата по факту: экспортированный файл повторно разбирается `exifr`, интерфейс показывает «было N полей метаданных, в файле осталось 0» (или предупреждение, если что-то осталось).
- Флаг «Удалить метаданные» переименован в «Ослабить след камеры (PRNU)» — метаданные удаляются всегда; нейтральное имя файла включено по умолчанию.
- `.gitignore` дополнен `.dev.vars`, `.wrangler/`, `public/ocr/*`, `public/mediapipe/`, `public/test/`.

### Отказоустойчивость

- Размытие работает без `ctx.filter`: `canvasBlurMode()` определяет поддержку фильтров и при её отсутствии (Safari до 18) использует пикселизацию вместо тихого пропуска.
- Недоступная модель детекции показывается как явное состояние «детекция недоступна» с отключённой опцией, а не как «объектов нет»; недоступность OCR отделена от ошибки распознавания (`ocr-unavailable` / `ocr-failed`).
- OCR: один singleton-воркер на страницу, повторное создание ограничено тремя попытками, `createWorker` гоняется с `errorHandler`, чтобы неудачная загрузка языка не зависала навсегда; воркер завершается при `pagehide`.
- Хуки возвращают машинные коды стадий и ошибок; сопоставление с текстами вынесено в компоненты, поэтому смена языка не перезапускает детекцию, OCR и разбор EXIF.
- `useAPIFetch`: таймаут 12 с, до двух повторов при 429 / 5xx / таймауте / сетевой ошибке, отмена запросов при смене фотографии, кнопка «Повторить» для транзиентных ошибок.
- Время съёмки хранится как настенные часы камеры (`shotDateLocal`) со смещением при наличии; погода и временные эвристики считаются по времени места, а не зрителя.
- Overpass: один общий запрос для POI и камер, разделяемый между параллельными вызовами; ответ с `remark` о таймауте не кэшируется и отдаётся как 504. Праздники: статический список государственных праздников Узбекистана, так как Nager.Date отвечает 204 для UZ.
- Экспорт: формат, который браузер не может закодировать, заменяется на JPEG с уведомлением; расширение берётся из фактического `blob.type`; лимит экспорта 16 Мп на iOS/iPadOS и 40 Мп на остальных платформах с предупреждением о понижении.
- Каждая секция обёрнута в `ErrorBoundary variant="inline"`; blob-URL предпросмотра отзываются при замене и при размонтировании.
