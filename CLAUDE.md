# CLAUDE.md — Found You (repo `meta-data`)

Guidance for Claude Code sessions in this repository. Product: https://foundyou.morgunov.tech/ — a browser-only photo privacy analyzer and cleaner. Read `README.md` for the full feature and privacy description; this file is about how to work in the code.

## Stack

- React + TypeScript SPA built with Vite; Cloudflare Pages for static hosting, Pages Functions (`functions/api/*.ts`) as the only server code. Exact dependency versions: `package.json` (do not hard-code them in docs).
- Browser-side engines: `exifr` (metadata), `@mediapipe/tasks-vision` (FaceDetector for faces + ObjectDetector with COCO labels for people/objects; WASM runtime and `.tflite` models self-hosted under `public/mediapipe`), `tesseract.js` (OCR, `rus+eng`, LSTM), `libheif-js` (HEIC fallback decoder), `maplibre-gl` (map, lazy-loaded).
- Node 22 (`.nvmrc`, `engines` in `package.json`). Tests: vitest. Lint: ESLint. Format: Prettier.

## Commands

```bash
npm ci
npm run prepare:assets   # copies Tesseract + MediaPipe WASM runtimes and the c2pa toolkit, downloads the .tflite models into public/ocr, public/mediapipe, public/c2pa (once)
npm run dev              # http://localhost:5173, /api/* served by functions/ via the Vite plugin
npm run lint
npm run typecheck        # tsc --noEmit over src, functions, vite.config.ts
npm test                 # vitest run — src/**/__tests__/*.test.ts
npm run build            # prepare:assets + typecheck + vite build → dist/
```

`prepare:assets` needs network access (storage.googleapis.com). The `.claude/launch.json` entry `vite-dev` starts the dev server for the browser preview.

## Conventions

**Design system (non-negotiable):** `border-radius: 0`; no `box-shadow`, gradients, emoji, or `font-weight: 700`; colours and type only from `--v4-*` tokens; sizes and gaps are literal px values (do not introduce `--space-*` or other token twins). DS component classes are `.v4-*`; every page-specific class is prefixed `.fy-` and lives in `src/styles.css`. Themes switch on `data-theme` on `<html>` (`light` implicit, `dark`, `high-contrast`); preference key `theme-preference`.

**i18n:** every user-facing string is a key in `messages.ru` with translations in `en` and `uz`; `MessageKey` is derived from the `ru` dictionary, so a missing key fails `typecheck`. Use `t('key', { param })`. Do not add `lang === 'ru' ? … : …` ternaries in new code (legacy ones remain in `heuristics/` and `sceneNarrative.ts`; convert when touching them). Hooks return machine codes (`DetectionErrorCode`, `OCRErrorCode`, stage ids) and never translated strings; components map codes to keys (see `*_KEYS` tables in `App.tsx`).

**Functions:** build each endpoint with `defineHandler` from `_geo.ts` (GET/HEAD only → 405, same-site check → 403, exceptions → 500 `internal-error`). Parse coordinates with `parseCoord`, round with `round4`/`coordKey`, call upstreams through `fetchUpstream` (shared `USER_AGENT`, 8 s timeout, no upstream error text to the client), cache with `withCache` using `cacheKey(name, …)`, respond with `json()` so every answer carries `nosniff`, `X-Robots-Tag: noindex` and correct `Cache-Control` (public only when `ok`). Body shape is `{ ok: true, data }` / `{ ok: false, error: '<kebab-code>' }`; statuses: 400 invalid input, 429 upstream rate limit, 502 upstream failure/invalid, 504 upstream timeout. `_headers` does not apply to Functions.

**Frontend:** explanatory text goes in `Explainer` next to the data it explains and is always visible — never behind a toggle, badge or «Pro» switch (raw data tables may collapse, explanations may not); blob URLs are revoked when replaced; heavy libraries are `import()`-ed lazily; new sections go inside an `ErrorBoundary variant="inline"`; visible status text uses `role="status"`.

## Privacy invariants (do not break)

1. The image, its pixels, filename and full metadata never leave the device. No upload, no third-party fetch with image data.
2. Place context requests (`useGeoContext`) send only 4-decimal rounded coordinates plus the capture date/time (country code + date for holidays). They start automatically when EXIF has GPS, so the section must always show what was sent (`geoDisclosure`) and the «Не запрашивать контекст места» switch; `localStorage['geo-context'] = 'off'` must stop every request and the map (OSM tiles) for all later photos. Adding any field to these requests is a privacy decision, not a feature.
3. Runtime assets (Tesseract worker/core/traineddata, MediaPipe WASM runtime and `.tflite` models, the c2pa worker and WASM) are self-hosted under `public/`; no CDN URLs at run time. Any new external host must also be added to the CSP in `public/_headers` — treat that as a privacy decision, not a config tweak.
4. Exported files are re-encoded through canvas and then passed through `stripContainerMetadata`; the "0 fields left" verification must stay literally true for JPEG and PNG.
5. No analytics, cookies, or fingerprinting; `localStorage` holds only `theme-preference`, `meta-data-lang` and `geo-context`.

## Testing layout

- All tests run with `npm test` (vitest; `include` pattern in the `test` block of `vite.config.ts`).
- Utility tests live next to the code in `src/utils/__tests__/*.test.ts` (`containerMetadata`, `cleanupSummary`, `shotDate`, heuristics, `story`, `timeProfile`, `deviceProfile`, `stance`, `plates`, `geotagTips`, `contentCredentials`, `share`, formatters); hook-level pure functions (OCR filters) in `src/__tests__/hooks/`.
- Functions tests live in `src/__tests__/functions/*.test.ts`, one file per endpoint plus `_geo.test.ts`, and share `_harness.ts` (`call`/`callJson` build a same-site `Request` and invoke `onRequest`, `mockFetch` stubs the upstream, `installCaches` fakes `caches.default`). Add a test there for every new endpoint or guard; remember a request without `Sec-Fetch-Site`/`Origin`/`Referer` answers 403 by design.
- Manual smoke: `public/test/IMG_20260614_183012.jpg` (GPS, Samsung EXIF) exercises the full flow in the dev server; it is git-ignored, so a fresh clone has none. `node scripts/make-exif-fixture.mjs in.jpg out.jpg --lat … --lon … --heading … --speed … --offset … --gps-time … --lens … --focal35 …` writes a full EXIF block (GPS, heading, speed, GPS time, offset, device, lens) into any JPEG for checking the location and «Как был сделан снимок» facts.
- `docs/handoff-2026-09-16.md` lists open decisions, unfinished work with implementation notes and the live-data checks to run once the sandbox network allows the upstream hosts.

## Do not

- Commit anything under `public/ocr/`, `public/mediapipe/`, or new binaries under `public/test/`; generated assets come from `prepare:assets`.
- Add CDN or third-party script/style/font URLs to `index.html` or the code; the CSP forbids them and the privacy promise depends on it.
- Add `--space-*` (or any parallel) design tokens; use literal sizes.
- Hard-code library versions in documentation; point to `package.json`.
- Commit `.env*`, `.dev.vars`, or `.wrangler/`.
- Edit `docs/audit-2026-09-15.md` to mark items done without verifying them in code.
