# Проверка узбекского словаря через Tilmoch.ai — 2026-09-24

Владелец предложил проверить узбекские тексты через Tilmoch (переводчик Tahrirchi). Публичного API у него нет,
поэтому 792 русские строки словаря (`messages.ru`, `src/i18n/index.tsx`) были прогнаны через веб-редактор
tilmoch.ai пачками по ~1 400 символов с нумерацией строк, а машинный узбекский сравнён с нашим `messages.uz`.
Это перекрёстная проверка машинным переводом, не вычитка носителем: расхождение с MT — повод посмотреть,
а не доказательство ошибки, и наоборот.

## Как

- Редактор tilmoch.ai — ProseMirror без `textarea`; текст вставлялся синтетическим событием `paste`,
  результат читался из второго элемента `.ProseMirror`. Направление ru → uz, стандартный (не Premium) режим.
- Строки нумеровались `N) …`, чтобы переводчик не терял выравнивание. Он всё же склеивал часть строк:
  первый проход дал 618 из 788 непустых, второй, пачками по 6 строк, — ещё 168. Итого **786 из 788**
  (не получены 4: `homeSignal_*` из-за склейки; пропущены).
- Сходство считалось по триграммам символов (Dice) после нормализации апострофов (‘ ’ ʻ ' → '),
  кавычек и плейсхолдеров. 8 ответов MT оказались обрезанными (короче 45 % исходника) и исключены.

## Результат

| Сходство с MT | Строк |
|---|---|
| ниже 0,2 | 75 |
| 0,2–0,4 | 64 |
| 0,4–0,6 | 122 |
| 0,6–0,8 | 202 |
| 0,8 и выше | 323 |

Низкое сходство почти всегда означает синонимы, а не ошибку: словарь чаще выбирает узбекское слово там,
где MT берёт русизм («ayoz» против «sovuq», «qal’a» против «qulf» у MT — там MT ошибся сам,
«mahalla», «kunduz», «g‘ira-shira»). Вручную просмотрены **200 наименее похожих строк** (сходство до 0,56);
строки выше этого порога отличаются формой слова или порядком и не смотрелись.

## Исправлено в словаре (`messages.uz`)

| Ключ | Было | Стало | Почему |
|---|---|---|---|
| `resolutionLabel` | Ruxsat | Surat o‘lchami | «Ruxsat» — «разрешение» в смысле permission; калька с русской многозначности |
| `privacyDiffResolutionChanged`, `privacyDiffResolutionSame` | Ruxsat: … / Ruxsat o‘zgarmaydi | O‘lcham: … / O‘lcham o‘zgarmaydi | то же |
| `homeFor` | Tarafdor | Foydasiga | «Tarafdor» — «сторонник»; в списке «за / против» нужно «в пользу» |
| `openMaps` | Google Maps | Google Maps’da ochish | пропал глагол |
| `qrKind_boarding` | bort talon | bortga chiqish taloni | стандартная формулировка авиакомпаний |
| `insightPoiEmpty` | Yaqinda … | Yaqin atrofda … | «yaqinda» — «недавно», а не «поблизости» |
| `poiCategory_convenience` | yaqin do‘kon | uy yonidagi do‘kon | «магазин у дома», не «ближний магазин» |
| `poiCategory_parking` | parkovka | avtoturargoh | официальный термин (вывески, ПДД) |
| `shotDate` | Suratga olingan vaqt | Suratga olingan sana va vaqt | в русском «дата и время» |
| `privacyDiffTitle` | O‘zgarishlar jamlanmasi | Tozalashdan keyin nima o‘zgaradi | заголовок отвечал не на тот вопрос |
| `manualMaskSurfaceRole`, `manualMaskDrawingHint` | niqob | maska | остальной раздел кисти говорит «maska» |

Оставлено сознательно: `compassShortE` «Sq» (сокращение sharq; MT даёт русскую «В»), `deviceFirmware`
«Proshivka» (принятый в узбекском IT русизм), `watermarkToggle` «Watermark qo‘shish», `stanceHeldLandscape`
«yotiq», `contentUnavailable` (перефразировано, смысл тот же).

## Чего эта проверка не даёт

Сходство с MT говорит о лексике, а не о естественности: пунктуацию, регистр, согласование и стиль носитель
увидит там, где метрика молчит. Пункт «проверка носителем» из плана остаётся открытым; этот файл —
список того, что уже не нужно ему показывать.
