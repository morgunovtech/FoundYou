## Phase 1: Technical Foundation — 91/100

### Обход и индексация
- ✅ `robots.txt` валиден, всё разрешено, `Sitemap:` указан; GPTBot, ClaudeBot, PerplexityBot, Google-Extended, Applebot-Extended, Bytespider, cohere-ai разрешены явно.
- ✅ `sitemap.xml` отдаётся как `application/xml`, содержит единственный URL.
- ⚠️ `<lastmod>2026-09-15</lastmod>` устарел: страница менялась 20.09, 24.09 и 26.09. Дата должна ставиться на сборке (см. артефакт D).
- ✅ Несуществующий адрес отвечает 404 своей страницей (с 26.09; до этого — 200 с `index.html`).
- ✅ `llms.txt` есть, 7 КБ, подробный.
- ❌ **Не проиндексирован ни один адрес** (Google, Bing; Яндекс отвечает капчей, ИКС домена 0). Роботы получают 200, `X-Robots-Tag: noindex` нет, meta robots `index, follow`. См. Action Plan, пункт 1.
- ⚠️ `hreflang` отсутствует, при этом страница отдаёт три языка по одному адресу. Язык выбирает `theme-init.js` из `navigator.languages`, то есть Googlebot (рендерит с локалью en-US) индексирует **английскую** версию и видит `<html lang="en">`, а `<title>`, `description` и `og:*` при этом русские; Яндекс с большой вероятностью получает русскую. Узбекская версия не индексируется нигде. Это не ошибка кода, это архитектура одного URL на три языка.

Выключается в дашборде: Pages → exifcleaner → Settings → Web Analytics. Если аналитика нужна — это решение о приватности, а не настройка.

### Meta-теги и превью

- ✅ `manifest.json`, иконки, `theme-color` под обе темы.
- ℹ️ `meta keywords` поисковики не читают с 2009 года; вреда нет, но это шум.

Это хороший продуктовый заголовок, но единственный H1 единственной страницы должен нести и запрос. ## Phase 5: Agentic Search Readiness — 40/100

### H. Три языковых входа в Vite (набросок)

```ts
// vite.config.ts → build.rollupOptions.input
input: {
  main: path.resolve(__dirname, 'index.html'),        // ru
  en: path.resolve(__dirname, 'en/index.html'),
  uz: path.resolve(__dirname, 'uz/index.html'),
  notFound: path.resolve(__dirname, '404.html')
}
```

Три `index.html` отличаются только `<head>` (title, description, og, JSON-LD, hreflang, `lang`) и статическим героем — их стоит генерировать из одного шаблона и словаря плагином `transformIndexHtml`, а не держать три копии руками; `src/__tests__/i18n/staticHero.test.ts` уже проверяет соответствие словарю и легко расширяется на три файла. В `initialLanguage(stored, browserLanguages)` добавить первый аргумент `pathLang` (из `location.pathname`): путь → сохранённый выбор → браузер. Переключатель языка вместо `setLanguage` делает переход на `/`, `/en/`, `/uz/` (состояние сбрасывается — фото всё равно не покидает вкладку). `theme-init.js` берёт `lang` из пути так же, чтобы первая отрисовка совпала.
