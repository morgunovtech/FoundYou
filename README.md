# Meta Data Insight

Meta Data Insight — одностраничное приложение на React, которое помогает оценить приватность фотографии перед публикацией: извлекает и показывает метаданные (EXIF/XMP/IPTC/ICC), строит карту по GPS, подтягивает контекст (адрес, погода на момент съёмки, объекты и возможные камеры поблизости) и позволяет скачать безопасную копию снимка. Все операции с изображением выполняются в браузере; Pages Functions используются только как прокси к открытым API — им передаются координаты и время, но не сам файл.

## Возможности

- **Локальное извлечение метаданных** (exifr): EXIF, XMP, IPTC, ICC, GPS — включая HEIC-оригиналы.
- **HEIC**: конвертация в JPEG прямо в браузере (heic2any) для превью и обработки.
- **Детекция объектов** (TensorFlow.js + COCO-SSD, lite_mobilenet_v2): люди, транспорт, животные — с рамками на превью.
- **Контекст по координатам** (через Pages Functions): обратное геокодирование (Nominatim), историческая погода на час съёмки в часовом поясе места (Open-Meteo Archive), заметные объекты и возможные камеры поблизости (Overpass).
- **Карта** (MapLibre GL + растровые тайлы OSM) с маркером и кругом точности.
- **Безопасная копия**: перекодирование через canvas всегда удаляет метаданные; опционально — ослабление PRNU-шума матрицы, размытие лиц по детекциям, ручные маски-кисти, «анти-поиск» (микрокроп/поворот/шум/сдвиг цвета), водяной знак, нейтральное имя файла, выбор качества JPEG.
- Три языка интерфейса (ru/en/uz), светлая/тёмная/контрастная темы.

## Ограничения (честно)

- Перекодирование через canvas **всегда** удаляет метаданные и ICC-профиль — режима «сохранить метаданные» нет; чекбокс управляет обработкой PRNU.
- Размытие лиц — эвристика поверх детекции «person»; проверяйте результат и при необходимости дорисуйте маску вручную.
- Историческая погода доступна с лагом архива (~5 дней) и только при наличии даты съёмки в EXIF.

## Локальная разработка

```bash
npm install
npm run dev
```

Приложение будет доступно на http://localhost:5173. Во время разработки Vite подключает Pages Functions из каталога `functions/` — запросы на `/api/*` исполняются тем же кодом, что и в продакшене.

## Проверки и сборка

```bash
npm run typecheck   # tsc --noEmit
npm run lint        # eslint
npm test            # unit-тесты утилит (tsx + node:assert)
npm run build       # typecheck + vite build → dist/
```

## Деплой на Cloudflare Pages

- **Build command**: `npm run build`
- **Build output directory**: `dist`
- **Functions directory**: `/functions`

Pages Functions (`functions/api/`, общая обвязка в `_shared.ts` — валидация координат, таймауты upstream 10 с, кэширование, проверка Origin):

- `reverse-geocode` — Nominatim (обратное геокодирование);
- `historical-weather` — Open-Meteo Archive (погодный срез на час съёмки, `timezone=auto`);
- `nearby-poi` — Overpass (объекты поблизости);
- `surveillance-candidates` — Overpass (места, где вероятны камеры).

Каждая функция возвращает компактный JSON `{ ok, data | error }` и не раскрывает внутренние детали ошибок.

## Ручной смоук-тест перед публикацией

- Загрузите JPEG с EXIF/GPS и HEIC ≥6 МБ: проверьте превью, метаданные, карту и блок контекста.
- «Скачать очищенную копию»: сравните, что рамки детекций и размытие совпадают с превью, метаданные в скачанном файле отсутствуют.
- Мобильная адаптация: основные операции на 360×640 и 768×1024.

## Безопасность и приватность

- Изображения не покидают браузер; конвертация, анализ и очистка выполняются через `<canvas>`/WebGL на клиенте.
- На Functions отправляются только координаты и дата/время съёмки.
- Функции проверяют Origin, ограничивают диапазоны координат и кэшируют ответы, чтобы не нагружать бесплатные API.
